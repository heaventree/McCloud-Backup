## Steps to Get a New Dropbox Access Token from a Refresh Token

### 1. **Obtain the Refresh Token (one-time setup)**

You must first go through the OAuth authorization flow with `token_access_type=offline` to receive a long-lived refresh token:

```
https://www.dropbox.com/oauth2/authorize?
  client_id=<APP_KEY>&
  response_type=code&
  token_access_type=offline&
  redirect_uri=<YOUR_REDIRECT_URI>
```

After the user authorizes, you'll receive an authorization code. Exchange it for access and refresh tokens via:

```bash
curl -X POST https://api.dropbox.com/oauth2/token \
  -d code=<AUTH_CODE> \
  -d grant_type=authorization_code \
  -d client_id=<APP_KEY> \
  -d client_secret=<APP_SECRET> \
  -d redirect_uri=<YOUR_REDIRECT_URI>
```

This returns both:

* A **short-lived access token** (expires in \~4 hours)
* A **long-lived refresh token**, which you store securely
  ([dropboxforum.com][1], [dropbox.com][2], [codemzy.com][3])

### 2. **Use the Refresh Token to Get a New Access Token**

Whenever needed, exchange the refresh token for a fresh short-lived access token:

```bash
curl -X POST https://api.dropbox.com/oauth2/token \
  -d refresh_token=<REFRESH_TOKEN> \
  -d grant_type=refresh_token \
  -d client_id=<APP_KEY> \
  -d client_secret=<APP_SECRET>
```

The response contains the new access token and its expiry—but **not a new refresh token**, since the same refresh token can be reused indefinitely (unless revoked) ([Stack Overflow][4], [dropboxforum.com][5], [Go2Share][6], [dropbox.tech][7]).

## Quick Reference

| Step | Description                                                           |
| ---- | --------------------------------------------------------------------- |
| 1    | Authorize with `token_access_type=offline` → get `authorization_code` |
| 2    | Exchange code for `access_token` + `refresh_token`                    |
| 3    | Use `refresh_token` to obtain new `access_token` as needed            |
| 4    | **Do not expect a new refresh token** on refresh—reuse the old one    |

## Additional Notes

* Refresh tokens **do not expire** automatically, though they can be revoked manually ([dropboxforum.com][8]).
* Dropbox's official SDKs (e.g., Python) can manage this flow for you. In Python, you can initialize the Dropbox client with the refresh token, and the SDK handles refreshing automatically ([Stack Overflow][9], [dropbox.tech][7]).

Example in Python:

```python
import dropbox

dbx = dropbox.Dropbox(
  app_key="<APP_KEY>",
  app_secret="<APP_SECRET>",
  oauth2_refresh_token="<REFRESH_TOKEN>"
)
# The SDK automatically handles refreshing the access token when needed
```
